Deploying Step Motor Application on Raspberry Pi:

Build the Application in RELASE mode.

Select TestLEDApp as startup project.


IMPORTANT ! !
In Solution Explorer select the TestLEDApp project 

Build --> Publish --> Folder:
	Target folder: ..\publishTestLEDApp\

	Profile settings 
		Deployment mode: Self contained
		Runtime: linux-arm64



Build --> Publish --> Click "Publish" button


Here you find concise steps to enable passwordless SSH from your Windows machine to the Raspberry Pi (recommended: use ed25519 keys):
	raspberry_pi_best_practice_start_guide.txt

Copy to Raspberry Pi:

C:\Users\niels\source\repos\FlightTracker3D\publishTestLEDApp


Open a powershell

Navigate to the folder where the applications are built.
C:\Users\niels\source\repos\FlightTracker3D

ssh pi@raspberrypi

Create a folder for the application:
mkdir TestLEDApp

From windows PC:
scp publishTestLEDApp\* pi@raspberrypi:~/TestLEDApp


From Raspberry Pi:

cd TestLEDApp/
chmod +x ./TestLEDApp



Comments:
Check if mode= LedHardwareMode.Real
